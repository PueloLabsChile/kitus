**El sentido de las movilizaciones, las huelgas, las elecciones y las luchas**

Siempre que nos hacemos una pregunta iluminamos una duda

Siempre que iluminamos una cueva ilustramos una sombra

Siempre que juntamos palabras sembramos un pensamiento

Siempre que compartimos pensamientos recogemos una esperanza

Uno siempre se pregunta **¿para qué?**

**¿Para qué las movilizaciones?**

Para denunciar, para iluminar, para ilustrar, para sembrar… para esperanzar

**¿Para qué la huelga?**

Para seguir creyendo, para seguir creciendo… para seguir luchando

Para ser realistas y seguir pidiendo lo imposible

**¿Para qué las elecciones?**

Para frenar el fascismo

Para evitar la pérdida de derechos

Para impedir el recorte de libertades

Para seguir creyendo en el futuro… para intentar mejorar el mundo

**¿Para qué las luchas?**

Para no acomodarnos

Para reclamar justicia social

Para que se marchen los tiranos y las tiranías de este mundo

Para que se vayan las desdichas y vuelvan las cosas no dichas

Para que mueran las guerras y nazcan las paces

Para que caigan las injusticias y sobresalgan las dignidades

Para que termine el genocidio y vuelva a florecer el olivo

Para que enterremos las tragedias y broten las sonrisas

Para hacer el amor y no la guerra

Para que leamos más y odiemos menos

Porque una lucha no es siempre una victoria, pero nunca será una derrota

“Quiero una huelga donde vayamos todos, / Una huelga de brazos, de piernas, de cabellos, / una huelga naciendo en cada cuerpo. (…) / Quiero una huelga grande, que hasta el amor alcance. / Una huelga donde todo se detenga, / el reloj / las fábricas / el plantel / los colegios / el bus / los hospitales / la carretera / los puertos. / Una huelga de ojos, de manos y de besos. / Una huelga donde respirar no sea permitido, / una huelga donde nazca el silencio / para oír los pasos / del tirano que se marcha.”

[Gioconda Belli (1997). El ojo de la mujer. Madrid: Visor libros, p. 89]

¡No olvidemos Gaza ni Cuba!

[J. Ignacio ´Iñaki` Chaves G.](https://www.pressenza.com/es/author/ignacio-chaves/)
